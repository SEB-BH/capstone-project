## About

The Capstone Project is the final project of the Software Engineering Bootcamp. It spans two project weeks and is designed to give you experience working like a developer while building something real that you can be proud to show.

You will complete the Capstone in one of **two tracks**:

- **Client Track** - work with a real client to discover, plan, build, test, deliver, and present a solution to a real need.
- **Startup Track** - identify a real problem or opportunity, validate it with potential users or customers, build and launch an MVP, and present the startup.

Both tracks share the same professional project process, but the exact technical scope and track-specific deliverables will depend on what you are building.
